Proposition 36.20.1. Let $X$ be a smooth projective threefold and $F$ a coherent torsion-free sheaf. Put

\[ \mathcal{E}^ i= \mathcal{E}xt^ i(F,\mathcal{O}_ X). \]
Then $F$ is locally free if and only if
\[ \mathcal{E}^1=\mathcal{E}^2=0. \]
It is reflexive if and only if $\mathcal{E}^2=0$ and $\operatorname {Supp}\mathcal{E}^1$ is a finite set of points, possibly empty. For a reflexive $F$, this becomes: $F$ is locally free if and only if $\mathcal{E}^1=0$.
